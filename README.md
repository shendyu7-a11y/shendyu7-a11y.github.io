# Aa Shendi Yusuf – Portfolio

Static website (no build step). Live on GitHub Pages.

## How to edit
- All text is in `index.html`. On github.com open the file, click the pencil (Edit), change the text, then "Commit changes". The site updates in 1–2 minutes.
- Images and PDFs are in `certs/`. To replace one, upload a file with the same name (Add file → Upload files).
- CV: replace `CV_Aa_Shendi_Yusuf.pdf` with the same file name.
